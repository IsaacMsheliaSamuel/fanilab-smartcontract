## Contributing Translations

We welcome community contributions for:
1. **Additional languages**: Spanish, Arabic, Mandarin, and others
2. **Additional documents**: Translating CONTRIBUTING.md, API.md, and other guides
3. **Translation improvements**: Feedback on existing translations

### Translation Guidelines

1. **Maintain accuracy**: Preserve technical terminology and keep the meaning intact
2. **Adapt for local context**: Adjust examples and references where appropriate for each market
3. **Consistency**: Use consistent terminology across all translated documents
4. **Test links**: Ensure all relative links point to correct documents
5. **Preserve formatting**: Keep all markdown formatting, code blocks, and structure

### How to Contribute a Translation

1. Fork the repository
2. Create a new directory under `docs/` with your language code (e.g., `docs/es/` for Spanish)
3. Translate the documentation files
4. Update this TRANSLATIONS.md file to list your new translation
5. Submit a pull request with your translation

Example PR title: `docs: add Spanish translation of README.md`

## Notes on Translations

### Character Encoding
All translation files use UTF-8 encoding to support special characters and diacritics.

### Terminology
Technical terms are generally preserved in English where they are widely recognized:
- "Smart Contract" / "Contrat Intelligent" / "Contrato Inteligente" / "Mkataba Akili"
- "Escrow" / "Depot en Caution" / "Depósito em Caução" / "Uhifadhi"
- "Blockchain" / "Blockchain" / "Blockchain" / "Blockchain"

### Community Review
Translations are reviewed by native speakers when possible to ensure quality and accuracy.
